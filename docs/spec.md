# 바이브코딩 공부 MVP 기획서

## 0. 문서 개요

- 문서 목적: 바이브코딩에 관심 있는 사람들이 공부 자료와 학습 기록을 나누는 커뮤니티의 MVP 범위를 정의한다.
- 서비스명: 바이브코딩 공부
- 현재 상태: 서비스 상세 설명이 입력되지 않아, 기존에 정한 서비스명과 소개 문구를 바탕으로 작성한 초안이다.
- 핵심 방향: 사용자는 바이브코딩으로 만든 완성 작품을 등록하고, 다른 사용자의 작품을 목록과 상세 화면에서 열람할 수 있다.

## 1. 서비스 정의와 주 사용자

### 서비스 한 줄 정의

바이브코딩에 관심 있는 사람들이 직접 만든 완성 작품을 공개하고 서로의 결과물에서 배우는 온라인 공간.

### 주 사용자

- 바이브코딩을 처음 접해 무엇부터 공부할지 막막한 입문자
- AI 도구를 활용해 직접 서비스나 결과물을 만들어보고 싶은 사람
- 자신의 학습 기록을 남기고 다른 사람의 경험에서 힌트를 얻고 싶은 사람

### MVP의 핵심 가치

1. 다른 사람이 바이브코딩으로 만든 완성 작품을 쉽게 발견한다.
2. 작품 설명과 링크를 간단히 등록해 자신의 결과물을 공유한다.
3. 개인별 완성 작품을 한곳에 모아 성장 과정을 확인한다.

## 2. 화면 목록

| 화면 | 목적 | 주요 내용 및 동작 | 로그인 필요 |
|---|---|---|---|
| 첫 화면 | 서비스의 성격을 알리고 탐색을 시작하게 한다 | 서비스명, 한 줄 소개, 핵심 소개 문구 3개, `둘러보기` 버튼 | 아니요 |
| 목록 | 등록된 완성 작품을 탐색한다 | 최신순 작품 목록, 제목, 대표 이미지, 요약, 제작자, 작성일, 태그, 상세 화면 이동 | 아니요 |
| 상세 | 완성 작품의 전체 내용을 확인한다 | 제목, 대표 이미지, 작품 설명, 제작자, 사용 도구, 태그, 작품·저장소 링크, 목록으로 돌아가기 | 아니요 |
| 등록 | 새로운 완성 작품을 공개한다 | 제목, 대표 이미지 URL, 요약, 작품 설명, 사용 도구, 태그, 작품·저장소 링크 입력, 등록 및 취소 | 예 |
| 로그인 | Google 계정으로 사용자 인증을 완료한다 | `Google로 계속하기`, 오류 안내, 로그인 완료 후 이전 화면 복귀 | 아니요 |
| 마이페이지 | 내 정보와 완성 작품을 관리한다 | 닉네임, 소개, 내가 등록한 작품 목록, 작품 수정·삭제, 로그아웃 | 예 |

### 지역 선택지

- 목록 필터와 등록 데이터의 광역 지역은 `서울`, `경기`, `인천`, `부산`, `대구`, `광주`, `대전`, `울산`, `세종`, `강원`, `충북`, `충남`, `전북`, `전남`, `경북`, `경남`, `제주`, `온라인`, `지역 미정`을 사용한다.
- `서울 성수동`, `부산 해운대구`처럼 세부 지역이 저장된 경우에는 앞의 광역 지역을 기준으로 필터링한다.

### 기본 사용자 흐름

1. 방문자는 첫 화면에서 `둘러보기`를 선택한다.
2. 목록에서 관심 있는 완성 작품을 선택해 상세 내용을 확인한다.
3. 작품을 등록하려는 사용자는 Google 계정으로 로그인한다.
4. 로그인한 사용자는 등록 화면에서 작품 정보와 링크를 작성한다.
5. 등록한 작품은 승인 절차 없이 즉시 공개되며 목록과 마이페이지에서 확인할 수 있다.

## 3. 저장해야 할 데이터

### 사용자(User)

| 항목 | 형식 | 필수 | 설명 |
|---|---|---:|---|
| 사용자 ID | UUID 문자열 | 예 | 사용자를 구분하는 내부 고유값 |
| 이메일 | 이메일 문자열 | 예 | 로그인 및 계정 식별에 사용 |
| 닉네임 | 문자열, 최대 30자 | 예 | 글에 표시되는 이름 |
| 자기소개 | 문자열, 최대 160자 | 아니요 | 마이페이지에 표시되는 짧은 소개 |
| 프로필 이미지 URL | URL 문자열 | 아니요 | 사용자 프로필 이미지 주소 |
| 가입일 | ISO 8601 날짜·시간 | 예 | 계정이 생성된 시각 |
| 수정일 | ISO 8601 날짜·시간 | 예 | 사용자 정보가 마지막으로 변경된 시각 |

### 완성 작품(Project)

| 항목 | 형식 | 필수 | 설명 |
|---|---|---:|---|
| 작품 ID | UUID 문자열 | 예 | 작품을 구분하는 내부 고유값 |
| 제작자 ID | UUID 문자열 | 예 | 사용자 데이터와 연결되는 값 |
| 제목 | 문자열, 최대 100자 | 예 | 목록과 상세에 표시되는 작품명 |
| 대표 이미지 URL | URL 문자열 | 예 | 목록과 상세에 표시되는 작품 이미지 |
| 요약 | 문자열, 최대 200자 | 예 | 목록에 표시되는 짧은 작품 소개 |
| 작품 설명 | 마크다운 문자열 | 예 | 작품의 목적, 특징 및 제작 과정 |
| 사용 도구 | 문자열 배열, 최대 10개 | 예 | 작품 제작에 활용한 AI·개발 도구 |
| 태그 | 문자열 배열, 최대 5개 | 아니요 | 작품 주제 및 유형 분류 |
| 작품 링크 | URL 문자열 | 예 | 실제 완성 작품을 확인할 수 있는 주소 |
| 저장소 링크 | URL 문자열 | 아니요 | GitHub 등 소스 저장소 주소 |
| 공개 상태 | 고정값 `published` | 예 | 등록과 동시에 공개됨을 나타내는 값 |
| 작성일 | ISO 8601 날짜·시간 | 예 | 작품이 처음 공개된 시각 |
| 수정일 | ISO 8601 날짜·시간 | 예 | 작품 정보가 마지막으로 변경된 시각 |

### 인증 세션(Session)

| 항목 | 형식 | 필수 | 설명 |
|---|---|---:|---|
| 세션 ID | 보안 문자열 | 예 | 로그인 세션 식별값 |
| 사용자 ID | UUID 문자열 | 예 | 로그인한 사용자와 연결되는 값 |
| 만료일 | ISO 8601 날짜·시간 | 예 | 세션이 만료되는 시각 |

## 4. MVP 기능 범위

### 포함 기능

- 반응형 첫 화면
- 완성 작품 목록 및 상세 조회
- Google 로그인 및 로그아웃
- 완성 작품 등록, 즉시 공개, 수정, 삭제
- 태그 표시
- 마이페이지에서 내 작품 조회
- 작품 좋아요 및 댓글 작성
- 회원 간 팔로우 및 팔로우 취소
- 필수 입력값 검증과 기본 오류 안내

### 이번 과정에서 만들지 않을 기능

- 대댓글
- 북마크
- 실시간 채팅 및 온라인 스터디 방
- 알림 및 이메일 발송
- 통합 검색, 정렬, 고급 필터
- 이미지·동영상 직접 업로드
- 유료 결제, 구독, 광고
- 관리자 페이지와 사용자 제재 기능
- 작품 사전 검수 및 승인 대기 절차
- 소셜 공유 및 초대 코드
- 학습 진도, 출석, 배지, 랭킹 등 게임화 기능
- 다국어 지원
- 모바일 앱

## 5. 완료 기준

- 모바일과 데스크톱에서 모든 MVP 화면을 사용할 수 있다.
- 방문자는 로그인 없이 공개 작품 목록과 상세를 볼 수 있다.
- 사용자는 Google 계정으로 로그인할 수 있다.
- 로그인한 사용자는 작품을 등록하고 자신의 작품만 수정하거나 삭제할 수 있다.
- 등록된 작품은 관리자 승인 없이 즉시 목록에 표시되고 상세 화면으로 연결된다.
- 비정상 입력이나 권한 없는 요청에 사용자 친화적인 안내가 표시된다.

## 6. 확정 사항

- 핵심 콘텐츠: 바이브코딩으로 만든 완성 작품
- 로그인 방식: Google 로그인
- 공개 정책: 등록 즉시 공개하며 관리자 사전 승인은 사용하지 않음
